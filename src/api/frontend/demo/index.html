Research Library MCP

A local-first MCP server that lets coding agents discover, summarise, organise, and ideate over arXiv research papers — entirely on your own machine.

Try Visual Panel View API Docs

Features

Everything a coding agent needs to do research, offline.

🔍

arXiv Search + Enrichment

Search arXiv and enrich results with citation counts, venue impact, and author data from Semantic Scholar — all free, no API keys required.

🔒

Entirely Local & Private

No cloud LLM calls. All embeddings, reranking, and generation run on your CPU or small GPU via quantized GGUF models. Your data never leaves your machine.

📊

Hybrid Vector Library

BGE embeddings + ChromaDB with hybrid vector + metadata retrieval. Filter by citations, venue, and category. Cross-encoder reranking for precision.

📝

Structured Summaries

Auto-generate concise summaries: problem statement, methodology, findings, ablations, discussion, limitations. Each section indexed for RAG retrieval.

💡

Idea Generation

Generate novel research ideas grounded in each paper's constraints, assumptions, and inductive biases. Each idea includes search queries for novelty checking.

✅

Novelty Re-verification

Check generated ideas against your local library and arXiv. The LLM judges overlap and returns a verdict: likely novel, needs review, or similar exists.

🖥️

Visual Supervision Panel

A clean web UI to inspect the library, view summaries and ideas, approve/reject ideas, and monitor every action the agent performed in real time.

🔌

MCP Protocol

Standard MCP server compatible with Cursor, Claude Code, Freebuff, and any MCP-aware agent. Nine tools covering the full research workflow.

How It Works

The agent workflow from query to insight.

1

Agent sends a research query

The coding agent calls research_search_papers with a natural-language query via the MCP protocol.

2

Search arXiv + enrich

The MCP server queries the arXiv API, optionally enriches results with Semantic Scholar citation/venue data, and stores papers in SQLite + ChromaDB.

3

Embed and index

Abstracts and titles are embedded with BGE and stored as vector chunks. Summary sections are indexed as they're generated for fine-grained RAG.

4

Follow-up queries

The agent calls research_query_library to retrieve relevant papers using hybrid vector + metadata retrieval with cross-encoder reranking.

5

Summarise, ideate, verify

The local LLM generates structured summaries, novel ideas grounded in constraints, and verifies novelty against the library and arXiv.

6

Human supervision

Every action is logged and surfaced in the visual panel. Researchers can inspect, approve/reject ideas, and remove irrelevant papers.

Quick Start

Three commands to get running.

1. Install
pip install -e ".[dev]"
2. Download models (~1.5 GB, uses HF_TOKEN for download only)
python scripts/download_models.py
3. Run the MCP server (for agents) or the web panel
python -m src.mcp_server # MCP stdio for agents python -m src.api.main # Web panel at localhost:8000
